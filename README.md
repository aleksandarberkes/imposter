# Imposter

Mobile-first website built with [Next.js](https://nextjs.org) and Tailwind CSS, hosted on [Vercel](https://vercel.com).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Edit `src/app/page.tsx` to get started.

## Scripts

| Script          | Purpose                      |
| --------------- | ---------------------------- |
| `npm run dev`   | Dev server with Turbopack    |
| `npm run build` | Production build             |
| `npm run start` | Serve the production build   |
| `npm run lint`  | Run ESLint                   |

## Deploying

Import the GitHub repo at [vercel.com/new](https://vercel.com/new). Vercel detects Next.js automatically; no config needed. Pushes to `main` deploy to production, other branches get preview URLs.

See `CLAUDE.md` for project conventions.
